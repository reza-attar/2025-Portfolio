# Machine-readable endpoints

Routes written for crawlers, agents and social networks. All of them are generated at build time.

* [llms.txt](llms-txt.md) - `/llms.txt`: a plain-text map of the site for LLMs and agents.
* [Resume as Markdown](resume-md.md) - `/resume.md`: the resume source as published.
* [Share image](og-image.md) - `/og`: the 1200 × 630 Open Graph card every page uses.
* [robots.txt](robots-txt.md) - `/robots.txt`: allows every crawler, AI crawlers named on purpose.
* [sitemap.xml](sitemap-xml.md) - `/sitemap.xml`: five pages plus every case study.
